# Заставка «Магазин Чорсу» — раскадровка

**Нить:** магазин открывается утром → полки заполняются → всё собирается в знак приложения (навес + «Ч») и надпись. Финальный кадр = знак, с которого начинается приложение.
**Формат:** 3,6 с · плоская 2D-векторная графика · 5 цветов: зелёный фон #1D5C45, тёмно-зелёный #12382B, светлый #F2F5F0, янтарный #E8B05A, коралловый #D9573B · ease-in-out, морфинг форм · движение в плоскости кадра, лёгкий 2D-наезд камеры.

## Референсы → что беру
- 04:02 «домик» (контур → заливка → оживает): линия становится объёмной формой.
- 06:33 UniKey (штрих рисует знак, буквы собираются по одной): сборка надписи по буквам.
- 06:36 «слои» (стопка схлопывается в простой знак): несколько форм перетекают в одну.

## Камера
2D-наезд 1,12 → 1,00 на протяжении сцен 1–2, лёгкий откат 0,97 на сборке знака и мягкая посадка в 1,00. Сдвиг по Y вместе с центром внимания.

## Риски и проверка
- Читается ли «Ч» после слияния пачек → проверить кадры 2,3–2,6 с.
- Морфинг рулона в навес без скачка → плотная последовательность 1,0–1,3 с.
- В приложении: портретный экран, без звука (браузер не даёт играть звук при запуске), пропуск по нажатию, reduced-motion → короткое появление.
