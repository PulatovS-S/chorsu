# Магазин Чорсу

Приложение учёта магазина: приход, терминал и касса, долги клиентов, инвентаризация, отчёты.

- `index.html` — приложение (работает на телефоне, ставится иконкой на экран, работает без интернета).
- `apps-script/Code.gs` — сервер базы, вставляется в Google Таблицу владельца.

В этом репозитории нет никаких данных магазина. Все записи хранятся только в Google Таблице владельца;
телефон подключается к ней по личной ссылке с ключом.
